# PlateDrop Web

This repository contains the web landing page for **PlateDrop**, a peer-to-peer food marketplace.

The site serves as a lightweight front-facing webpage to introduce the product, provide basic information, and direct users to the PlateDrop mobile app.

---

## 🚀 Project Overview

PlateDrop is a peer-to-peer food marketplace designed to make sharing and discovering homemade food easier and more accessible.

This repository focuses on:
- A simple, responsive landing page
- Clear product introduction and branding
- Fast load time and clean UI

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
